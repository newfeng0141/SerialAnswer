# SerialAnswer

《视觉第一阶段第二次培训 · 串口》作业：为「星门织仪」判题机写一支抄报器，经串口把三路信标校准入账并重开星门。

## 运行环境

- Ubuntu 22.04（WSL 亦可）
- Python 3（只用标准库：`os` / `select` / `struct` / `termios` / `tty`）
- 判题机 `Starweave.x86_64` 启动后，窗口左上角给出串口路径（形如 `/dev/pts/2`）

## 用法

```bash
# 端口默认 /dev/pts/2，可覆盖：PORT=/dev/pts/3 python3 answer.py ...
python3 answer.py ledger          # 读底账：扫描峰值 / 留档峰值 / 修复刻度 / 星门状态
python3 answer.py aim 64.8        # 定向到 64.8° 并等停稳
python3 answer.py sample          # 取样：样本号 / 实测角 / 三路光强
python3 answer.py bottom 4 1 55.1 960   # 底片入账：样本号 通道 实测角 光强
python3 answer.py open            # 确认合相（三路留档都 >= 门限才发）
```

## 协议实现要点

| 项 | 值 |
|---|---|
| 帧格式 | `A5 5A | 03 | TYPE | SEQ | LEN | DATA | CRC_L CRC_H`，共 8+LEN 字节 |
| CRC | CRC-16/CCITT-FALSE：init `0xFFFF`，poly `0x1021`，不反射，xorout `0x0000` |
| 参与校验 | `VER TYPE SEQ LEN DATA`（4+LEN 字节） |
| 串口参数 | 115200 8N1，原始模式（`tty.setraw`） |
| 字节序 | 多字节字段与小端 f32 均低字节先行 |
| 应答类型 | 01/02/03/20 的应答为 TYPE 高位；30/40 统一回 `0x80`（载荷偏移 0 才是接口号） |

接口：`01` 铭牌、`02` 取样、`03` 底账、`20` 定向、`30` 底片、`40` 确认合相。

## 解题思路

1. `01` 读铭牌，拿到三路粗测方位、轴转速、合相门限；
2. 对每一路：`20` 定向到粗测方位附近 → `02` 取样看光强；
3. 光强与偏差近似线性（每偏离 1° 掉 20 点）：`偏差 = (1000 - 光强) / 20`，据此逼近峰顶；
4. 达到门限后 `30` 底片入账（样本号必须用刚取样的那个）；
5. 三路留档都过线后 `03` 核对，再发 `40` 开启星门。

## 实测结果

- 三路留档峰值：1000 / 996 / 1000
- 修复刻度 100，星门已开启

## 踩到的坑

- **落帧不能只找同步字**：载荷与 CRC 里也可能出现 `A5 5A`，必须按 LEN 定帧尾并校验 CRC；
- **读超时可能少于请求字节数**，必须累计缓冲、循环解析；
- 判题机部分应答帧的 CRC 高字节与规程计算值差 `0x0100`（疑似模拟器实现瑕疵），代码里对这种已知差异放行，其余仍严格校验；
- 连发请求要留间隔，窗口在转动时偶发不回帧，需要重试。
